MicroDeck 1.0.0 is the first full release.

MicroDeck can now update itself: when a new version is out, tap Download and install. It downloads the update from GitHub, checks it against the release's SHA-256 file and checks that it's signed by the same developer, then hands it to Android.

This adds one permission, Install unknown apps (REQUEST_INSTALL_PACKAGES), used only to install MicroDeck's own updates. Android asks you once before allowing it and asks you to confirm each update. If you'd rather not allow it, Open in browser downloads the update the old way.
